# Examen Parcial 3 de Escalables

## Requisitos
- Node.js
- Docker o Podman (para la base de datos)

## 1. Levantar la base de datos y el Backend
- cd backend
- npm install
- docker-compose up -d
- npm run dev

## 2. Levantar el Frontend
En otra terminal:
- cd frontend
- npm install
- ng serve

Abre el navegador en http://localhost:4200
